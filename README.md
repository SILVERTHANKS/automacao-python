# Automação Python

Repositório de estudos práticos em Python, com exercícios de lógica, funções, listas, programação orientada a objetos e pequenos programas de automação. O objetivo é registrar minha evolução e consolidar fundamentos importantes para desenvolver soluções úteis.

## Conteúdo

| Arquivo | O que pratico |
| --- | --- |
| `app.py` | Primeiro programa e saída no terminal |
| `caixa.py` | Menu interativo, condicionais, repetição e operações de caixa |
| `cafe.py` | Exercício prático de lógica |
| `lampada.py` | Conceitos iniciais de classes e objetos |
| `lista.py` | Manipulação de listas |
| `poo.py` | Fundamentos de programação orientada a objetos |
| `usuario.py` | Exercícios com dados de usuário |
| `vend.py` | Exercício de lógica de vendas |
| `main.py` | Verificação do ambiente e demonstração de bibliotecas Python |

> Este é um repositório de aprendizagem. Os exemplos são pequenos exercícios e não devem ser usados como sistemas financeiros ou de produção.

## Tecnologias

- Python 3
- Git e GitHub
- VS Code
- Pandas e PyAutoGUI no exemplo `main.py`

## Como executar

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Clone o repositório:

   ```bash
   git clone https://github.com/SILVERTHANKS/automacao-python.git
   cd automacao-python
   ```

3. Execute um exercício pelo terminal, por exemplo:

   ```bash
   python app.py
   ```

   Para executar o exemplo que utiliza Pandas e PyAutoGUI, instale essas dependências primeiro:

   ```bash
   python -m pip install pandas pyautogui
   python main.py
   ```

No Windows, se necessário, use `py` no lugar de `python`.
